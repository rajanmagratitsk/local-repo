4th Semester Syllabus

Tribhuvan University - Bachelor of Computer Applications

Subjects Overview

Numerical Methods

Focuses on solving mathematical problems using computational techniques like interpolation, root finding, and numerical integration.

Operating Systems

Covers process scheduling, memory management, deadlocks, file systems, and working of modern operating systems.

Database Management System

Learn SQL queries, normalization, ER diagrams, relational models, and database design principles.

Scripting Language

Introduces scripting with JavaScript or Python including DOM manipulation and basic automation tasks.

Software Engineering

Study SDLC, agile models, testing, project planning, and software design techniques.

Project Work

Practical implementation of real-world projects using learned programming and development skills.

About This Semester

The 4th semester of TU BCA focuses on both theoretical and practical knowledge. Students build strong concepts in system-level understanding and software development.
